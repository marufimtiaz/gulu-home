# Our Home — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A multi-room, interactive wedding-night site — a paper-cutout house at night whose windows light up as she completes each room's toy, ending with the nameplate on the door.

**Architecture:** Vite + vanilla ES modules + GSAP. A hash router mounts one scene at a time through a fixed scene contract; `state.js` is the only persistence; `fx/`, `sound/`, `photos.js`, `ui/drag.js` are shared contracts that every scene consumes. Each scene owns its own folder (index.js, scene.css, strings.js, strings.bn.js) so tasks never touch each other's files.

**Tech Stack:** Vite 8, GSAP 3, pnpm 12, Vitest (happy-dom) for units, Playwright (mobile Pixel 7 + desktop) for e2e, nginx:alpine in Docker.

**Spec:** `docs/superpowers/specs/2026-10-21-our-home-design.md` — read it first, in full. Every task below argues from it.

## Global Constraints

- Node 20 locally (`fnm`), pnpm 12.4.1 (`packageManager` is pinned). `pnpm exec vite`, never global.
- Fonts: Fraunces (display), Caveat (hand), DM Sans (body), Hind Siliguri + Atma (Bengali). Already loaded by `index.html` / `i18n.js`. Use the CSS vars `--display`, `--hand`, `--body`, `--bn`.
- Palette and shape tokens come **only** from `src/styles/tokens.css` (`--paper`, `--ink`, `--berry`, `--mustard`, `--butter`, `--night`, `--night-deep`, `--indigo`, `--lamp`, `--lamp-glow`, `--line`, `--pop`, `--pop-sm`, `--bounce`). No new hex colours in scene CSS except where the spec names one (kitchen ingredient colours come from config).
- Art is inline SVG written in code. No raster images except `public/photos/` and icons.
- All pointer work goes through `src/ui/drag.js` (`onDrag`, `onRotate`, `onHold`, `hit`). Dragged elements get `touch-action: none` in CSS.
- Every rAF loop goes through `loop()` from `src/ui/motion.js` (pauses in background tabs). Every scene checks `ctx.reduced` and skips ambient/zooms when true.
- Scenes never import each other, never touch `localStorage`, never edit `src/content/strings*.js` (they own `src/scenes/<id>/strings.js` + `strings.bn.js`).
- All user-visible text comes from `ctx.t()` (scene strings) or `ctx.c()` (content). No hard-coded English in scene JS. Every string added to `strings.js` gets a Bengali draft in `strings.bn.js`.
- Unmount must leave nothing behind: kill GSAP timelines (`gsap.killTweensOf`, `tl.kill()`), stop loops, remove window listeners. `ctx.onCleanup(fn)` is the easy path.
- Mobile first: design for 390×844 portrait; must also look intentional at 1280×800.
- Commit per task on your own branch, message style: `feat(kitchen): recipe scene` — end every commit with the attribution line given in the task prompt.
- **Feel rules (spec section "Feel") are mandatory for every scene:**
  - Timing: build every multi-step moment with `moment()` / `beat()` / `T` / `EASE` from `src/ui/choreo.js`. No `setTimeout` for choreography. `ctx.complete()` / `ctx.go()` only at a timeline's end.
  - Interactivity: `press()` on every interactive element, `poke()` on decorative scenery, `wobble()` on draggables, `nudge()` toward the next step (retarget with `.set()` as the room progresses, `.stop()` when done) — all from `src/ui/feel.js`, registered with `ctx.onCleanup`.
  - Responsive: every scene spec includes a `VIEWPORTS` loop calling `checkLayout(page, [interactive selectors], '<scene>-<vp.name>')` (desktop project only, as in `tests/e2e/responsive-house.spec.js`), plus one `pressLatency(page, sel) < 100` assertion. Review every screenshot, including landscape phone (844×390), and give landscape a deliberate layout.
- Run before claiming done: `pnpm exec vitest run` and `PORT=<your port> pnpm exec playwright test tests/e2e/<yours>.spec.js tests/e2e/routing.spec.js`.

  - `starfield(container, { count = 60, shooting = false }) → stop()` — SVG `<svg class="stars">` filling the container, `count` stars of radius 0.6–1.8, 30% twinkle via CSS animation with random delays. `shooting: true` fires a shooting star every 4–7 s across the top third. Reduced → no twinkle, no shooting.
  - `fireworks(container, { duration = 6000 }) → Promise<void>` — canvas appended to container, bursts every 400–700 ms in `--berry`, `--mustard`, `--pink`, `--sky`, `--butter`, resolves after `duration` and removes the canvas. Reduced → three quick static bursts then resolve.

  - `confetti({ duration = 3000 }) → Promise<void>` — paper rectangles over `#fx-layer`.

import { makeScrubber } from '../../src/scenes/living/clock.js'
const start = new Date(2022, 3, 20, 4, 30), end = new Date(2026, 9, 22, 20, 0)
describe('scrubber', () => {
  it('14 anticlockwise turns reach the start, clamped', () => {
    const s = makeScrubber({ start, end })
    expect(s.t()).toBe(1)
    for (let i = 0; i < 14; i++) s.angle(-2 * Math.PI)
    expect(s.t()).toBeCloseTo(0, 5)
    s.angle(-6)
    expect(s.t()).toBe(0)
